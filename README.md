# MNIST Neural Network from Scratch (Python 3 Updated)
Python 3 refactored implementation of Michael Nielsen's classic neural network with an interactive live inference canvas in Google Colab.

This repository is an updated, Python 3-compatible version of the neural network implementations originally created by **Michael Nielsen** in his book *Neural Networks and Deep Learning*. 

### Key Updates & Enhancements:
* Fully migrated core scripts (`network.py`, `mnist_loader.py`) from Python 2 to Python 3.
* Implemented an advanced data loading pipeline for modern Google Colab runtime environments.
* Added a live, JavaScript-powered interactive HTML canvas inside the notebook for real-time handwritten digit inference.
